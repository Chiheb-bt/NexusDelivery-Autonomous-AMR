## 🚀 About Me

I am a **Lead Robotics Systems & Embedded AI Architect** passionate about engineering end-to-end autonomous cyber-physical systems that solve real-world industrial bottlenecks.

My work spans the complete robotics vertical:
- **Vision-Centric Autonomy:** Designing zero-LiDAR, zero-GPS autonomous navigation pipelines using active stereo RGB-D perception, pinhole depth geometry, and sub-10ms edge neural accelerators.
- **Embedded Software & ROS 2:** Architecting deterministic, fail-safe ROS 2 nodes in C++ and Python with 100% test coverage and hardware-in-the-loop validation.
- **Mechatronics & Digital Fabrication:** Rapid prototyping of laser-cut aluminum flat-pack chassis, closed-loop FOC motor controllers (ODrive), and smart BMS LiFePO4 power architectures.
- **AI Safety & Autonomous Fleet Ops:** Deploying low-latency operator cockpits, Augmented Reality HUDs, cryptographic OTP cargo security, and runtime guardrails.
